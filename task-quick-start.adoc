= Guida rapida a Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Inizia a usare Google Cloud NetApp Volumes assegnando il tuo ruolo di NetApp Console, aggiungendo le credenziali e individuando un sistema.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"] link:task-add-roles.html["Assegnare i ruoli"]
[role="quick-margin-para"]
Dalla NetApp Console, assegnare i ruoli corretti ai membri.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html["Aggiungi credenziali"]
[role="quick-margin-para"]
Nella NetApp Console, aggiungi le credenziali di Google Cloud NetApp Volumes.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"] link:task-create-system.html["Aggiungi un sistema"]
[role="quick-margin-para"]
Nella NetApp Console, individua un sistema utilizzando le credenziali, il progetto Google Cloud e la regione supportata.
